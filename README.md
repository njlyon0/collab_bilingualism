# R / Python Bilingualism

[![Zenodo DOI](https://img.shields.io/badge/Zenodo%20DOI-10.5281/zenodo.17201351-blue.svg)](https://doi.org/10.5281/zenodo.17201351)

These materials demonstrate a range of increasingly complex coding operations in both R and Python. For each operation, synonymous outputs are achieved in parallel in both languages to help other coders new to one or the other language in their efforts at becoming "bilingual".
